# 七種類型

每種類型寫：何時用、骨架、不放什麼。骨架是章節順序；標題換成這份內容自己的話。

- 教學、操作指南、參考、解釋來自 [Diátaxis](https://diataxis.fr/)。Diátaxis 指出混淆類型界線是很多文件問題的根源；「一份只做一種」是這個 skill 自己的規則。
- 決策紀錄的完整模板在 [decision-record.md](decision-record.md)。

## 怎麼選

| 讀者打開時在問 | 類型 |
|---|---|
| 「我想學會這個，從哪開始？」 | 教學 |
| 「我要完成 X，步驟是什麼？」 | 操作指南 |
| 「這個參數、欄位、上限是什麼？」 | 參考 |
| 「為什麼是這樣？」 | 解釋 |
| 「當時選了什麼、為什麼？」 | 決策紀錄 |
| 「我該選哪個？」 | 方案頁 |
| 「現在怎樣了？我要處理什麼？」 | 狀況報告 |

- 一份內容同時回答兩個問題：拆成兩份，互相連結。

## 教學

**何時用**：讀者是新手，要照著做一遍，做完學會一件事。

**骨架**

1. 做完會得到什麼：一句話，附完成後的樣子。
2. 開始前要準備的東西。
3. 編號步驟。每步寫要做的動作與會看到的結果。
4. 做完了：確認成功的方法，下一步讀什麼。

**不放**

- 選項與分支：只給一條一定走得通的路。
- 原理：放連結到解釋。
- 完整參數表：放連結到參考。

## 操作指南

**何時用**：讀者已經會基本操作，要完成一件具體的事。

**骨架**

1. 標題寫目標：「怎麼＿＿」。
2. 適用條件與前提。
3. 編號步驟。條件寫在動作前面：「如果＿＿，就＿＿」。
4. 確認完成的方法。
5. 常見問題：一題一行，附解法。

**不放**

- 教學式的鋪陳與鼓勵。
- 為什麼這樣做：放連結到解釋。
- 跟目標無關的功能。

## 參考

**何時用**：讀者要查一個事實。

**骨架**

1. 一句話說這份涵蓋什麼範圍。
2. 照產品本身的結構分節：模組、指令、端點、欄位。
3. 每一項欄位相同：名稱、型別或值、預設、限制、範例。

**不放**

- 步驟：放連結到操作指南。
- 意見與建議。
- 歷史與理由：放連結到解釋或決策紀錄。

## 解釋

**何時用**：讀者要理解一件事為什麼這樣。

**骨架**

1. 一句話結論：它是什麼、為什麼這樣設計。
2. 背景：要解決的問題、限制。
3. 運作方式：一張圖加文字。一張圖只畫一層。
4. 取捨：這樣做得到什麼、付出什麼、不適用的情況。
5. 相關：決策紀錄、參考。

**不放**

- 步驟與指令。
- 完整規格表。
- 過程與歷程：放連結到決策紀錄或 issue。

## 決策紀錄

**何時用**：已經做了一個決定，而且值得記。標準見 [decision-record.md](decision-record.md)。

**骨架**：背景、考慮過的選項、決定、取捨與後果、信心程度、何時重新檢討。

**不放**

- 設計細節與規格：放進解釋或參考。決策紀錄不是設計指南。
- 還沒做的決定：那是方案頁。
- 討論經過。

## 方案頁

**何時用**：要讀者在 2 個以上的選項裡做決定。

**骨架**

1. 第一屏，照 [structure-rules.md](structure-rules.md)〈第一屏〉：
   - 結論：要決定的問題、建議選哪個、一句理由、信心程度（高／中／低）。
   - 要讀者做的事：選哪個、什麼時候前、怎麼回覆。
   - 還沒解決的風險。
2. 選項並排：每個選項欄位相同，「做法、好處、代價」。代價不能空白。
   - 「維持現狀」也列一個選項。不列時，寫一句為什麼不可行。
   - 沒有把握建議哪個：照樣給建議，信心程度寫「低」，並寫要補什麼證據才能確定。
3. 依據與前提：每個結論的來源，以及它成立的條件：資料、規模、日期。
4. 沒有證據的地方：明寫。
5. 明細：收合。

- 多個決定放同一頁：每個決定一節，每節都用上面的骨架。第一屏列出全部決定與各自的建議。

**不放**

- 已經否決、不用讀者選的選項：最多一行帶過。
- 研究過程：只留結論與來源。
- 決定之後的實作細節。

## 狀況報告

**何時用**：讀者要知道現在怎樣、哪裡要他處理。

**骨架**

1. 第一屏，照 [structure-rules.md](structure-rules.md)〈第一屏〉：
   - 結論：整體狀態，一句話。
   - 要讀者處理的事：每項一句，附期限與連結。
   - 風險：會影響什麼、什麼時候。沒有可做動作的風險不列在這裡，放進「不用處理」。
2. 要處理的項目：放前面，每項欄位相同。
3. 狀態項照「要不要讀者處理」分組。不用處理的合成一節「不用處理」，每組一行，不逐項加狀態標記與欄位。
4. 數字明細：摘要的數字要能從這裡加總。

**不放**

- 做事的經過與時間線：連到 issue。
- 跟讀者無關的內部細節。
- 沒有變化的項目逐條列出。

# 查證規則

每個模式寫出事實時都照這份。事實包括：價格、配額、GA 或 Preview、區域可用性、服務限制。

## 規則

1. **不憑記憶。** 每次都重新查。
2. **只用官方來源。** 雲端廠商的文件、價格頁、API、官方 skill 與 MCP。第三方文章只當線索。
3. **附來源。** 每個事實附 URL 與查詢日期（`YYYY-MM-DD`）。
4. **事實與推論分開。** 推論標「推論」，寫出根據哪些事實。
5. **查不到就標「未驗證」。** 寫出查過哪裡；不要填一個看起來合理的數字。
   - 來源有歧義（區域、方案、級距不確定）也標「未驗證」。
   - 用其他區域的價格代替時，標「推論」並寫出代替的區域。
6. **算術用腳本。** 金額與用量一律用 `python3` 算。
7. **標區域與幣別。** 單價寫區域與 USD；換算台幣時，匯率附來源與日期。
8. **先查會淘汰候選的事實。** 區域可用性、硬限制、最大的幾個費用項目先查；已淘汰的候選查到足以確認淘汰為止。

## 管道順序

1. 官方 MCP（有裝的話）。用法見雲檔。
2. 官方文件的 Markdown 版。網址規則見雲檔。
3. 官方 HTML 頁面（WebFetch）。
4. 都失敗：標「未驗證」，寫出試過的 URL。

MCP 沒裝就直接用第 2、3 種，不要停下。

## 讀價格

- 來源與陷阱見雲檔。
- 記下區域與方案（隨需、承諾使用、Spot）。
- 階梯計價照實際級距算，不取平均。
- 計算機只給使用者核對，不當證據。
- 免費額度與 credits 另列一行，不直接扣進月費。

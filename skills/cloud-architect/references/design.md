# 設計檢查清單

design 模式用。每一項都要有對應的設計，或寫明「不需要」與理由。不能空著。

| 項目 | 要寫出的設計 |
|---|---|
| 網路 | 網段、公開與私有子網、對外入口、出站路徑 |
| 高可用與災難復原 | 可用區與區域配置、備份方式；RTO 與 RPO 的目標值與達成方式 |
| IAM | 角色與權限範圍、服務身分、人員存取方式 |
| 加密與機密管理 | 傳輸中與靜態加密、金鑰管理、機密存放與輪替 |
| 監控告警 | 要收的指標與日誌、告警條件、通知對象 |
| 擴展 | 擴展方式與觸發條件、上限與配額 |

- 每項寫出用到的服務；事實照 [verification.md](verification.md) 附來源。
- RTO、RPO 沒有給：照 [discovery.md](discovery.md) 第 8 題的預設，標「假設」。

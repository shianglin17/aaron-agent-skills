# 圖與互動

選圖的種類、做圖文連動時照這份。圖的畫法照對應的 skill；這裡只寫說明站特有的規則。

## 圖的種類

| 讀者的問題 | 圖 | 用哪個 skill |
|---|---|---|
| 系統由哪些部分組成？ | 架構圖（全景） | `diagram-design` |
| 一個請求怎麼走？ | 時序圖或步驟流程圖 | `diagram-design` |
| 資料怎麼存？ | ER 圖 | `diagram-design` |
| 資料從哪來、到哪去？ | 資料流程圖 | `diagram-design` |
| 狀態怎麼變？ | 狀態圖 | `diagram-design` |
| 量有多大、花多少？ | 長條、堆疊、Sankey | `dataviz`（Sankey 用 `diagram-design`） |
| 誰負責什麼、哪些情況怎麼處理？ | 矩陣 | `diagram-design` |
| 什麼時候做了什麼、接下來做什麼？ | 時間軸 | `diagram-design` |

- 一頁一張主圖；先選最能回答該頁問題的那種。
- SVG 的畫法、深淺色可讀性照 `artifact-diagramming`。

## 一張圖載多個維度

| 視覺通道 | 代表 |
|---|---|
| 顏色 | 誰負責：自家程式、模型、外部服務 |
| 線寬 | 量：請求數、資料量 |
| 虛線 | 沒用到、未實作、待決定 |
| 虛線框 | 部署單位或邊界（例如「後端」） |

- 每張圖附圖例，列出用到的每種顏色與線型。
- 連線只畫水平與垂直；連線標籤放在線的中段。

## 圖文連動

- 每頁一張主圖加說明面板。寬螢幕面板在右側並 sticky；窄螢幕移到圖下方。
- 點節點或連線：面板換成該處的說明、關鍵數字、程式碼位置；其他元素變暗。
- 再點一次或按 Esc：回到預設項目。
- hover：預覽高亮，不換面板。
- 鍵盤：Tab 移到節點；Enter 或空白選取；左右鍵換到上一個或下一個並選取。

## 漸進揭露

| 層 | 放什麼 |
|---|---|
| 第一層（面板預設可見） | 一句話加關鍵數字 |
| 第二層（點開） | 細節、程式碼位置 |
| 表格 | 一律收進 `<details>` |
| 更深的細節 | 連到決策文件或下一頁 |

- 不做 3D、不做無限畫布、不做縮放平移。
- 要看下一層：點一下展開子元件，或連到專頁。

## 無障礙與版面

- SVG 有 `<title>`、`<desc>`，用 `aria-labelledby` 指過去。
- 節點與連線：`tabindex="0" role="button" aria-label="…"`；選取狀態用 `aria-pressed`。
- 面板：`aria-live="polite"`。
- SVG 外包橫向捲動容器（`overflow-x: auto`），SVG 設 `min-width`。不畫手機版與桌面版兩套座標。
- HTML 的可點目標（nav、`summary`、按鈕）至少 44px 高。
- 有 `prefers-reduced-motion` 時關掉轉場。
- 有「跳到主要內容」連結。
